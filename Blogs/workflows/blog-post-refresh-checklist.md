# Blog Post Refresh Checklist

Use this checklist before recommending a refresh, merge, redirect, or new Shopify blog post.

## Existing Article Review

- Confirm article URL, blog, handle, title, author, publish date, and last updated date.
- Identify target keyword and search intent.
- Check whether the article has a featured image and useful alt text.
- Check whether the title and intro match the searcher's problem quickly.
- Check whether headings answer related questions clearly.
- Check whether the article links to relevant products, collections, and related guides.
- Check whether older product names, specs, prices, warranty details, or claims need verification.
- Note whether the article overlaps another post enough to merge or redirect.

## SEO And Conversion Upgrade

- Add a clear answer near the top for the primary query.
- Add a comparison table when shoppers are choosing between products or setups.
- Add product-specific proof: dimensions, setup constraints, customer examples, team/pro usage, video, or testimonial.
- Add internal links to the strongest buying pages.
- Add related-article links to strengthen the topic cluster.
- Add FAQ entries only when they answer real buyer objections.
- Tighten meta title and description for clarity and click intent.

## Human Review Gate

- Product accuracy checked.
- Brand voice checked.
- Claims checked.
- Links checked.
- Images checked.
- Recommendation marked as `draft`, `ready for review`, or `approved to publish`.
